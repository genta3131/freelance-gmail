# 🎯 MULAI DI SINI - WorkFlow Hub

## ⚡ Setup dalam 2 Menit

```bash
# 1. Login Supabase
supabase login

# 2. Link project (atau buat baru)
supabase link

# 3. Push database
supabase db push

# 4. Generate .env.local
supabase status --output env > .env.local

# 5. Start
npm install
npm run dev

# 6. Register di http://localhost:3000
# User pertama = Admin otomatis!

# 7. Deploy
vercel
```

**DONE! 🎉**
