## 🚀 CARA DEPLOY (3 Langkah Mudah)

### 1️⃣ Setup Supabase (5 menit)

```bash
# Login
supabase login

# Link/create project
supabase link

# Push database
supabase db push

# Simpan credentials dari:
supabase status
```

### 2️⃣ Push ke GitHub (sudah ✅)

```bash
git add .
git commit -m "Ready to deploy"
git push origin main
```

### 3️⃣ Deploy ke Vercel (5 menit)

**Via Dashboard (Termudah):**

1. Buka https://vercel.com
2. Import project dari GitHub
3. Pilih repo: `genta3131/freelance-gmail`
4. Set environment variables:
   ```
   NEXT_PUBLIC_SUPABASE_URL = (dari supabase status)
   NEXT_PUBLIC_SUPABASE_ANON_KEY = (dari supabase status)
   ```
5. Click Deploy!

**DONE! URL deployment akan muncul dalam 2-3 menit** 🎉
