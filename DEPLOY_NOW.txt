┌─ STEP 2: Setup Supabase (PENTING!) ─────────────────────────────┐
│                                                                  │

│                                                                  │
│  supabase login                                                  │
│  supabase link                                                   │
│  supabase db push                                                │
│  supabase status                                                 │
│                                                                  │
│  SIMPAN output dari "supabase status":                          │

┌─ STEP 3: Deploy ke Vercel ──────────────────────────────────────┐
│                                                                  │
│  1. Buka browser: https://vercel.com                            │
│                                                                  │
│  2. Login dengan GitHub                                          │
│                                                                  │
│  3. Klik "Add New..." → "Project"                               │
│                                                                  │
│  4. Import repository: "genta3131/freelance-gmail"              │
│                                                                  │
│  5. Configure Project:                                           │
│     • Framework Preset: Next.js (otomatis detect)               │
│     • Root Directory: ./                                         │
│     • Build Command: (biarkan default)                          │
│     • Output Directory: (biarkan default)                       │
│                                                                  │
│  6. Environment Variables (KLIK "Add"):                         │
│                                                                  │
│     Name: NEXT_PUBLIC_SUPABASE_URL                              │
│     Value: https://xxxxx.supabase.co (dari step 2)             │
│                                                                  │
│     Name: NEXT_PUBLIC_SUPABASE_ANON_KEY                         │
│     Value: eyJhbG... (dari step 2)                              │
│                                                                  │
│  7. Klik "Deploy"                                               │
│                                                                  │
│  8. Tunggu 2-3 menit...                                         │
│                                                                  │
│  9. DONE! URL deployment akan muncul! 🎉                        │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
